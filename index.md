# Planning Framework

Rules for a planning repo, in two tiers: the product side — charter, initiatives, epics, milestones, product
requirements, decisions, and mockups, each rule carrying a stable, citable `planning:<slug>` id — and the engineering
side — engineering requirements, assumptions, specs, slices, and decisions, each rule carrying an `planning:<slug>` id.

Read [`./context/index.md`](./context/index.md) when working in or changing a planning or requirements repo, or to
resolve a cited `planning:` id to the file that owns it.
